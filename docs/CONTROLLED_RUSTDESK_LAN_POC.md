依赖主机 Python 3、`nsenter`、Docker、systemd 和已存在的 `alpine:3.20.3` 镜像，不会自动下载镜像。脚本检查固定隔离项目、网络和专属卷，仅创建独立合成用户、设备与短时令牌；从三个不同容器网络来源发送不含 token 的 `RequestRelay`，真实内部 API 负责签发授权。内部密钥和令牌不写入输出。

七组场景已实测通过：双端各一次核销及未过期重放拒绝、错误 IP 不占名额、令牌撤销 `ERR-2303`、禁用用户 `ERR-2308`、禁用目标设备 `ERR-2307`、关闭目标中继 `ERR-2309`、API 停挂超时 `ERR-239B`。四类撤销和 API 停挂都覆盖第一端核销前以及第一端已核销、第二端未核销两个时序；拒绝时连接关闭、日志错误码与数据库剩余名额一致，恢复后同一授权可核销。

停挂 API 前先预设 20 秒自动恢复，并检查 API 进入 stopped 状态而 hbbr 仍存活；正常结束、异常或可处理的中断都会恢复 API 并清理夹具。若进程被强制杀死，独立定时器仍可恢复 API，探针容器最多 600 秒后退出，数据库夹具需另行核对。签发服务会按原业务逻辑清理过期授权；本次结束后测试用户/设备/令牌与中继授权均无残留，原测试账户、设备审批及策略复核未变，API 健康接口为 200。脚本保护自测和实机非隔离目标拒绝检查通过，语法及 Python 自测加入本地验收，CI 触发路径已补充。

该结果覆盖真实 API 到 hbbr 的调用链；hbbs 实际签发、官方客户端负向提示、跨网络和独立端点身份仍待验收。

本轮自动验收后已主动关闭局域网 PoC，并取消本轮关闭定时器；探针容器及 API 恢复定时器无残留，生产容器与原回环测试容器持续运行。后续官方客户端联调需重新启动 PoC 并设置有限测试窗口。
